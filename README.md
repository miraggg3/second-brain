# Второй мозг — Telegram Mini App

Заметки и трекеры жизни внутри Telegram. Оформление — «полевой журнал»:
днём бумага в клетку и чернила, ночью — синька чертежа.

## Данные: только на устройстве

- Все записи лежат в **Telegram DeviceStorage** (в обычном браузере — localStorage).
  Удалил Telegram или вышел из аккаунта на устройстве — записи удалились вместе с ним.
- Сервер **не хранит** ни заметок, ни тренировок. В его базе только факты оплат.
- Телефон и ПК — разные хранилища. Перенос — через экран **«Мои данные»** (кнопка ⇅):
  - **Отправить файл в чат с ботом** — бот присылает `.json` в твой чат (сервер только пересылает,
    ничего не сохраняет); на ПК скачиваешь его из чата;
  - **Скачать .json** — на ПК, в Telegram Desktop и браузере;
  - **Скопировать как текст** — запасной вариант без сервера.
- Импорт: **выбрать файл** или **вставить текст** → **Объединить** (записи с обоих устройств
  складываются, у одинаковых остаётся более свежая) или **Заменить всё**.
  Файл проверяется построчно: битые записи отбрасываются, приложение не сломается.
- Там же — экспорт заметок в Obsidian (.zip) и полное удаление данных.

## Что есть

| Вкладка | Функции |
|---|---|
| **День** | привычки с крестиками и сериями, вода стаканами, сон, вес, настроение по шкале, свои трекеры ★ |
| **Зал** | журнал тренировки (подходы вес × повторы, секундомер, подстановка прошлых весов), серии недель, карта посещений |
| **Заметки** | карточки с #тегами, поиск, редактор на линованной бумаге |
| **Прогресс** | вес, сон, вода, настроение, привычки за 30 дней; рекорды и 1ПМ по упражнениям ★ |

### Premium за Telegram Stars ★
**Месяц — 99** (подписка) · **Навсегда — 499** · **Спасибо — 50**.
Открывает безлимит привычек (бесплатно 3), свои трекеры, рекорды в зале, цвета чернил.
Цены — в `server/server.ts` → `PLANS`.

## Стек

- **TypeScript** везде: ошибки ловятся до запуска.
- Интерфейс: **Preact** + **@preact/signals** (≈4 КБ, быстрый старт в Telegram), сборка **Vite**.
- Шрифты Unbounded / Golos Text / JetBrains Mono вшиты в сборку (без запросов к CDN).
- Сервер: `server/server.ts`, без зависимостей — Node 22.18+ запускает TypeScript напрямую.

```
src/
  main.tsx App.tsx       старт, навигация, таб-бар
  store.ts storage.ts    состояние и хранение на устройстве
  backup.ts              экспорт / проверка / объединение копий
  domain.ts              логика зала и привычек
  premium.ts theme.ts    Stars и оформление
  charts.tsx ui.tsx      графики, формы, иконки
  screens/               экраны
  styles.css             дизайн
server/server.ts         бот + API + раздача dist/
```

## Запуск

Нужен Node.js 22.18+.

```
npm install
npm run build          # проверка типов + сборка в dist/
copy server\.env.example server\.env   # впиши BOT_TOKEN и WEBAPP_URL
npm start              # сервер: http://localhost:3000
```

Разработка с горячей перезагрузкой: `npm run dev` (Vite, API проксируется на :3000).

Mini App работает только по **HTTPS**. Для теста — туннель:
`cloudflared tunnel --url http://localhost:3000`, адрес впиши в `WEBAPP_URL`.
Для продакшена — любой хостинг с Node; папку `server/data/` (оплаты) держи на постоянном диске.

## Оплата

1. Приложение шлёт `initData` на `/api/invoice`, сервер проверяет подпись Telegram и создаёт
   `createInvoiceLink` в `XTR` (для подписки — `subscription_period`).
2. `openInvoice` открывает оплату, бот отвечает на `pre_checkout_query`, получает
   `successful_payment` (и продления), пишет статус в `server/data/db.json`.
3. Приложение спрашивает `/api/me` и включает Premium.

Команды бота: `/start`, `/paysupport`, `/terms`, `/refund <user_id> <charge_id>` (только `ADMIN_ID`).
